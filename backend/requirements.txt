# hard-caps thinc<8.3.0, and thinc 8.2.x's compiled numpy_ops Cython
# extension was built against numpy 1.x's C-API. thinc's own metadata
# only declares numpy>=1.19 with no ceiling, so pip is free to install
# numpy 2.x alongside it — which it will load at runtime and immediately
# crash with "numpy.dtype size changed, may indicate binary

# together keeps every other numpy floor in this file satisfied
